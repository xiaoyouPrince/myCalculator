> **需求追溯**：[REQ-004](./requirements/REQ-004-simple-attendance-model.md) · 研发节点：[rd-log.md](./rd-log.md)

## 1. 设计原则（为什么这样拆）

1. **录入要简单**：不要「日历角色 + 实际记录」双层选项；周六日默认休息。
2. **工时申报是一本账**：统计项目人力投入，**凡上班都按同一套申报规则算**，与是否加班工资无关。
3. **加班工资 vs 调休是两本账**：
   - **加班时长 / 有效加班** → 算加班工资
   - **调休额度** → 以后请调休假用，**不进加班工资**
4. **休息日主动出勤**才区分「加班」和「换调休」；公司安排的周末上班用「补班」。

## 2. 录入选项

按日历日切换可选类型（`WorkLogKind.pickerCases(for:)`）：

| 日历 | 可选 | 默认新开编辑 |
| --- | --- | --- |
| 周一～五 | 正常上班、不上班 | 正常上班 |
| 周六、日 | 补班、加班、换调休、不上班 | 不上班 |

| `WorkLogKind` | UI 文案 | 月格角标 |
| --- | --- | --- |
| `work` | 正常上班 | （无） |
| `makeupWork` | 补班 | **班** |
| `weekendOvertime` | 加班 | **加** |
| `weekendCompensatory` | 换调休 | **调** |
| `off` | 不上班 | 格内短标「休」 |

说明：补班角标刻意用「班」，表示按正常工作统计，避免和「加」混淆。

## 3. 公共：出勤时长与工时申报

对所有上班类型（正常上班 / 补班 / 加班 / 换调休）：

- **出勤分钟** = `max(0, 下班 − 上班)`，再换算出勤小时 `H`
- **工时申报**（项目人力，与类型无关）：

| 出勤小时 `H` | 工时申报 |
| --- | --- |
| `H < 10` | `max(0, H − 1)`（扣午饭 1h） |
| `H = 10` | `H`（不扣） |
| `H > 10` | `max(0, H − 2)`（扣午饭 + 晚饭共 2h） |

不上班：出勤、申报、加班、调休均为 0。

---

## 4. 分类型：加班工资账 vs 调休账

### 4.1 正常上班 / 补班（`work` / `makeupWork`）

算法完全相同。

| 字段 | 公式 |
| --- | --- |
| 加班时长 | `max(0, H − 10)`（只有超过 10h 的部分） |
| 有效加班 | 加班 &lt; 1 → 0；否则 `floor(加班 × 2) / 2`（0.5 档） |
| 调休额度 | 0 |

### 4.2 加班（休息日 · 加班工资，`weekendOvertime`）

**全部出勤都算加班时间**，再按午饭 / 晚饭档位扣减（**不是**「超 10h 才计加班」）。

| 出勤小时 `H` | 加班时长（工资账） |
| --- | --- |
| `H < 10` | `max(0, H − 1)` |
| `H = 10` | `H` |
| `H > 10` | `max(0, H − 2)` |

| 字段 | 公式 |
| --- | --- |
| 工时申报 | 仍用 §3 |
| 有效加班 | 同上：加班 &lt; 1 → 0；否则 `floor(加班 × 2) / 2` |
| 调休额度 | 0 |

对照例：`10:21–18:26` → `H ≈ 8.08` → 申报 **7.08**，加班 **7.08**，有效加班 **7.00**。

### 4.3 换调休（`weekendCompensatory`）

| 字段 | 公式 |
| --- | --- |
| 工时申报 | 仍用 §3 |
| 加班 / 有效加班 | **固定 0**（不进加班工资） |
| 调休额度 | 默认 = `H`；若上下班时间段**覆盖整段** `12:00–13:00`（开始 ≤ 12:00 且结束 ≥ 13:00），则 `max(0, H − 1)` |

对照例：

| 时间 | 调休额度 |
| --- | --- |
| `09:00–18:00`（覆盖午休） | 8.00（9 − 1） |
| `14:00–18:00`（不覆盖） | 4.00 |

## 5. 速查对照表（同一组上下班）

假设 `09:00–20:00`，`H = 11`：

| 类型 | 申报 | 加班 | 有效加班 | 调休额度 |
| --- | ---: | ---: | ---: | ---: |
| 正常上班 / 补班 | 9.00 | 1.00 | 1.00 | 0 |
| 加班（休息日） | 9.00 | 9.00 | 9.00 | 0 |
| 换调休 | 9.00 | 0 | 0 | 10.00 |

假设 `09:00–18:00`，`H = 9`：

| 类型 | 申报 | 加班 | 有效加班 | 调休额度 |
| --- | ---: | ---: | ---: | ---: |
| 正常上班 / 补班 | 8.00 | 0 | 0 | 0 |
| 加班（休息日） | 8.00 | 8.00 | 8.00 | 0 |
| 换调休 | 8.00 | 0 | 0 | 8.00 |

## 7. 易混点（改代码前先对一下）

| 误解 | 正确理解 |
| --- | --- |
| 休息日「加班」= 平时「超 10h 才加班」 | 否。休息日加班是**全勤算出勤加班再扣饭** |
| 申报扣饭 = 加班扣饭（休息日） | 档位相同（&lt;10 / =10 / &gt;10），但休息日加班的「扣饭」作用在**加班账**，平时加班作用在「超 10h」 |
| 换调休也按 &lt;10 扣 1、&gt;10 扣 2 | 否。换调休只看是否覆盖 **12:00–13:00** 扣 1h |
| 补班要显示「补」 | 产品定角标为「**班**」 |
