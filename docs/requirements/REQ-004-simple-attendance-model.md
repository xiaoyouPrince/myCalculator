## 背景

REQ-001～003 的「日历角色 + 实际记录」双层编辑过于复杂，违反提效初衷。本需求收敛为简洁模型，**取代**对 `dayRole` / `rest-day-overtime` 的依赖。

## 目标

- 用户只选：**不上班**，或上班三类之一
- 工时申报：任何上班类型都按正常工作日规则统计（项目人力）
- **周末加班** vs **周末调休** 两本账分开

## 选项与算法

周六日默认休息；工作日选项为「正常上班 / 不上班」；休息日选项为「补班 / 加班 / 换调休 / 不上班」。

| 类型 | 工时 + 工时申报 | 加班时长（加班工资） | 调休额度 |
| --- | --- | --- | --- |
| 正常上班 | 正常规则（&lt;10h 扣午饭 1h；&gt;10h 扣午饭+晚饭 2h） | 超 10h 部分 | 0 |
| 补班 | 同上 | 同上 | 0 |
| 加班（休息日·加班工资） | 申报仍按正常规则 | **出勤全计加班**；&lt;10h 扣午饭 1h，&gt;10h 扣午饭+晚饭 2h | 0 |
| 换调休（休息日） | 申报仍按正常规则 | **固定 0** | 出勤小时；若时间段覆盖 **12:00–13:00** 再扣 1h |
| 不上班 | 0 | 0 | 0 |

## 范围

1. 去掉录入面板的 `dayRole` / 「按日历默认」
2. `WorkLogKind` 收敛为：`work` / `weekendOvertime` / `weekendCompensatory` / `off`；旧 kind / dayRole 加载时兼容迁移
3. `WorkMetrics` 增加 `compensatoryLeaveHours`；默认计算规则消化三类上班
4. 月格短标签与底色简化；详情不再展示日历角色
5. CSV：去掉「日历角色」，增加「调休额度」；下线或移除 `rest-day-overtime` 规则（避免再干扰）
6. 更新 README / 计算规则指南 / 扩展说明；REQ-003 标为已取消（被本需求取代）

## 不做

- 年假/病假等细分标签
- 调休补班单独类型
- 浏览器扩展立刻消费调休字段

## 验收标准

- [ ] 录入只有「正常上班 / 周末加班 / 周末调休 / 不上班」，无日历角色
- [ ] 休息日「加班」`10:21–18:26`（约 8.08h）：申报 7.08，加班约 7.08（全计加班再扣午饭），有效加班约 7.0
- [ ] 休息日「换调休」`09:00–18:00`：申报 8，加班 0，调休额度 8（扣午休 1h）
- [ ] 休息日「换调休」若不覆盖 12:00–13:00（如 `14:00–18:00`）：调休额度 = 出勤小时（不扣）
- [ ] 旧数据能打开；旧请假类记为不上班
- [ ] 侧栏/导出能看到调休额度合计或列
- [ ] 构建通过
