## 目标

月视图一眼能看出「本来是什么日」和「实际记了什么」，降低误点、误录成本。

## 范围

1. 未录入日：按周末 / 已标假日给淡底色（空格仍可点进编辑）
2. 已录入上班：保留工时摘要；周末加班 / 补班等可加小角标
3. 已录入休息或假：短标签（休 / 假 / 年假…）
4. 打开未录入日时，用日历默认预填 `dayRole`（与 REQ-001「按日历默认」一致）

## 不做

- 计算规则变更
- 国家节日 API / 本地节日库全量导入（可选后续）

## 验收标准

- [x] 当月格子角色底色可读，且不破坏「当月深色 / 非当月浅色」既有规则
- [x] 周末加班、补班等有可辨识角标或等价提示
- [x] 非工作记录短标签清晰，不挤爆单元格
- [x] 对照 [`../month-view-rendering-postmortem.md`](../month-view-rendering-postmortem.md) 做一次视觉验收
