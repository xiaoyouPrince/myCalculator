## 目标

把「日历上这天本来怎样」和「实际记录怎样」拆开，让周末加班、法定放假、调休补班都能完整编辑。

## 范围

1. 新增 `dayRole`：`workday` / `weekend` / `publicHoliday` / `makeupWorkday`
2. `logKind` 沿用现有 `WorkLogKind`；文案上「调休」改为「调休休息」（补班走 `dayRole`）
3. 录入面板三段：今天是什么日 → 实际做什么 → 仅上班时显示时间
4. 提供「按日历默认」：工作日 / 周末按系统日历推断；法定假、补班首版手选
5. 旧 JSON 无 `dayRole` 时按日期回填；`kind` 行为保持兼容
6. 日 / 周 / 月录入面板统一改造

## 不做

- 月格着色、角标（REQ-002）
- 休息日加班计算规则变化（REQ-003）
- 节日库 / 自动调休日历
- 浏览器扩展字段同步（REQ-003）

## 验收标准

- [x] 可保存并再次打开带 `dayRole` 的记录
- [x] 旧数据加载不丢；缺省 `dayRole` 按工作日/周末推断正确
- [x] 周末 / 法定假 / 补班日均可选择「上班」并录入上下班时间
- [x] 「调休休息」与「调休补班」语义在 UI 上可区分
- [x] 日 / 周 / 月三处录入行为一致
- [x] 现有工时计算数值与改造前一致（本需求不改算法）
